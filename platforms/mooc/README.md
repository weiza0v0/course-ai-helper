# MOOC 测验 AI 答题助手

中国大学 MOOC（icourse163.org）测验的 **AI 答题工具**：在测验页控制台**粘一次脚本**，之后全自动 ——
采集题目 → 上传本机助手 → 多模态大模型（带**矩阵/微积分/概率统计**计算工具）解题 → **答案直接填回页面**。

> ⚠️ **本工具只填不交卷**：答案勾好后会把提交按钮圈出来，交卷永远由你自己点。

```
┌──────────────┐  ①粘一次脚本   ┌────────────────┐  ②自动解题   ┌──────────────────┐
│ MOOC 测验页   │ ───────────▶ │ 本机助手(8787)  │ ─────────▶ │ 多模态大模型      │
│ (F12 控制台)  │              │ config.toml 配 │            │ + calc / matrix   │
│              │ ◀─────────── │                │ ◀───────── │ + calculus/stats  │
└──────────────┘  ③轮询答案    └────────────────┘   答案      │ + web_search/fetch│
        └── ④把答案直接勾进页面（不提交）                        └──────────────────┘
```

## 快速开始（Windows）

1. 用记事本打开 **`config.toml`**，填上 `api_key`（其它一般不用改）。
2. 双击 **`启动.bat`** → 黑窗口起来并自动打开网页 `http://127.0.0.1:8787/`。
   - 免安装：文件夹自带 `runtime\node.exe`（便携版 Node v22）。
3. 打开 MOOC 测验页，**先点「开始测验」**进入答题界面。
4. 在助手网页上点「复制一键脚本」→ 回测验页按 `F12` →（若提示不允许粘贴，先输入 `allow pasting` 回车）→ 粘贴 → 回车。
5. 完事。助手网页能看到实时进度（每题调了什么工具、思考了什么、答案是什么），答案会自动勾进页面。
   **核对无误后自己点「提交答案」。**

为什么必须手动粘这一次？因为这个脚本要在**你已登录的页面**里跑。粘完它一直活着，所以答案能直接推回页面，全程不需要再复制粘贴任何东西。

## 六个工具

计算全部**本地完成、零依赖**（`lib/math/*` 是自己写的），不调任何外部计算服务。

### `calc` —— 通用表达式求值

```
+ - * / % ^（^ 也接受 **），pi、e、inf，隐式乘法 2x / 3(x+1) 都能识别
向量 [1,2,3]、矩阵 [[1,2],[3,4]]；矩阵*矩阵=矩阵乘，向量*向量=点积
例：det([[1,2],[3,4]])   inv([[4,7],[2,6]])   normalcdf(1.96)   comb(10,3)
需要符号量时用 vars：{"expression":"a+b+d","vars":{"a":1,"b":2,"d":3}}
```

### `matrix` —— 结构化线性代数

| 能力 | op |
| --- | --- |
| 行列式 / 逆 / 秩 / 迹 / 转置 / 维数 | `det` `inv` `rank` `trace` `transpose` `shape` |
| 行简化阶梯形（含主元列） | `rref` |
| 加减乘 / 幂 | `add` `sub` `mul` `pow` |
| 解线性方程组 Ax=b（带残差验证） | `solve` |
| **特征值（任意实方阵，支持复根）** | `eigen` |
| LU / QR 分解 | `lu` `qr` |
| 零空间基 | `nullspace` |
| 范数（Frobenius / 1 / 2 / ∞） | `norm` |

### `calculus` —— 微积分

| 能力 | 说明 |
| --- | --- |
| **符号求导** | 任意阶；多项式/三角/指数/对数/商/链式/幂指函数都行；给 `at` 同时返回该点导数值 |
| **积分** | 给 `lower`/`upper` → 自适应 Simpson 数值定积分；不给 → **符号原函数**（多项式、sin/cos/exp/ln、线性复合） |
| **极限** | 双侧/单侧，Richardson 外推，能识别发散到 ±∞ |
| **求根** | 表达式可写 `x^2-5x+6=0`，扫描+二分+牛顿，返回区间内**全部实根**并给出代入残差 |
| Taylor 展开 | 指定展开点与阶数，输出各项系数 |
| 级数求和 | Σ 从 `from` 到 `to`，附收敛性判断 |
| 化简 | `simplify` |

### `stats` —— 概率统计

| 能力 | 说明 |
| --- | --- |
| 描述统计 | n/均值/中位数/众数/样本与总体方差/标准差/四分位/极差/偏度/峰度 |
| 分布 | normal、t、χ²、F、binom、poisson、exp —— pdf / cdf / **反函数(分位数)** |
| 假设检验 | 单样本 t、双样本 t（Welch **和** 合并方差）、配对 t、z 检验、卡方拟合优度、卡方独立性（可选 Yates 校正）、单因素方差分析 |
| 回归/相关 | 一元线性回归（斜率/截距/r/R²/标准误/t/p）、Pearson、Spearman |
| 其他 | 组合排列 C(n,k)/P(n,k)、贝叶斯后验 |

### `web_search` / `web_fetch`

Bing 优先、DDG 兜底；抓网页正文去标签。用于查证定义、定理、公式、题目出处。

## config.toml

改完保存，在网页上点「**重载配置**」即可生效，**不用重启**。

```toml
[server]
port = 8787              # 本地服务端口
open_browser = true

[model]
base_url = "https://api.deepseek.com/v1"   # 任何 OpenAI 兼容接口
api_key  = ""                              # 必填（只在本机，不下发到浏览器）
model    = "deepseek-flash"                # 必须是支持图片输入的多模态模型
reasoning_effort = "max"                   # 思考强度：off / low / high / max
temperature = 0
concurrency = 3          # 同时解几道题
max_tool_rounds = 4      # 每题最多几轮工具调用（用完强制模型收尾作答）
use_tools = true
timeout_seconds = 300
max_retries = 3          # 撞 429/5xx 时的重试次数（指数退避，尊重 Retry-After）

[app]
auto_solve = true        # 收到题目就自动开解
auto_fill = true         # 出答案后自动填回页面并勾选
poll_seconds = 2
fill_interval_ms = 400   # ★ 两次勾选的间隔：错开页面的草稿写请求，避免被平台判"并发限制"
limit_backoff_ms = 3000  # 撞到平台"并发限制"弹窗后的退避等待
```

### 关于 MOOC 平台自己的「并发限制」

测验页**每勾一个选项就会发一次 `saveDraftAnswers` 草稿写请求**。脚本一秒内把 10 题连点完，
平台就会弹「**提示：并发限制，请稍后再试**」——这是平台侧的限流，跟模型 API 无关。本工具三层防护：

1. **限速勾选**：每题之间留 `fill_interval_ms`（默认 400ms），把草稿写请求错开；
2. **限流退避**：每次勾选前检测限流弹窗，发现就自动关掉、退避 `limit_backoff_ms` 再继续；
3. **复核补勾**：填完通读一遍页面实际勾选状态，发现没勾上的（被限流打断）退避后补勾，并在控制台报出仍未生效的题数。

另外网页题目预览的图片是经本地代理抓的，代理侧也加了并发闸（同时最多 3 个），避免一屏几十张图把题库 CDN 打爆。

**思考强度**是准确率关键：实测同一题 `low` 只用 256 个推理 token，默认(high) 598，`max` 更多。
数学题别关，默认 `max`。模型的思维链会显示在网页日志里（灰色斜体 💭 行）。

**并发**：实测接口 3/5/8 路并发都返回 200，没有硬上限；但真实解题请求又长又重，更容易撞限流，
所以保留重试（`max_retries`）比盲目调大 `concurrency` 更稳。

## 常见问题

**控制台提示 "Warning: Don't paste code..."**
先输入 `allow pasting` 回车，再粘。

**脚本说"连不上本机助手 / 上传失败"**
黑窗口关了，或它正在解上一份卷（返回 409）。重启助手即可；脚本会自动把题目 JSON 放进剪贴板，可走网页上的「备用：手动粘贴」。

**选项是禁用的（脚本提示"有 N 个选项是禁用状态"）**
还没点「开始测验」，或这次测验已交过卷 —— 点「再做一次」再来。

**某道题 AI 答了空白**
工具轮数用尽会**强制模型收尾作答**；若仍空白，日志会出现 `模型没给出可解析的答案`，可在答案表里手改，再用「复制填答脚本」补上。

**`web_search` 不可用**
网络到 Bing/DDG 不通。不影响解题，模型会只用本地数学工具。

**判断题的 A 到底是「正确」还是「错误」**
**逐题都不一样**（实测同一份卷子里 Q6 的 A 是「正确」、Q7 的 A 是「错误」）。
所以模型一律回答**选项字母**，脚本再按页面实际选项点击；网页答案表旁边会标出"这个字母代表什么"（如 `A=错误`），方便你一眼核对。

**弹「并发限制，请稍后再试」**
这是 MOOC 平台自己的限流（不是模型的）。脚本已内置限速+退避+复核补勾，正常情况下会自动关掉弹窗继续；
如果仍反复出现，把 `config.toml` 里的 `fill_interval_ms` 调大（如 800）再重跑。

**端口被占用**
自动往后找（8787→8788…），以黑窗口打印的地址为准。

## 安全与使用边界

- **永不自动交卷**：代码里根本没有提交动作，最后一步永远由你点。
- **没有 `eval` / `new Function`**：表达式由自研解析器解析成 AST 再求值，标识符必须在白名单里。
  早期版本用 `new Function` + 字符白名单，被 `process.exit(1)` 逃逸过一次（真把测试进程退掉了），已彻底重构。
- API Key 只存在 `config.toml`（本机文件），**不下发到浏览器**；网页只知道"已配置"和一个掩码。
- 控制台脚本上传/取答案需要 token（每次启动随机生成，只注入到服务端渲染的脚本里）；CORS 只放行本机与 MOOC 域名。
- 服务只监听本机，别把端口暴露到公网，否则等于送人一个免费 LLM 代理。
- 本工具是答题辅助，多数课程把"独立完成"写进了学术诚信条款。**怎么用、用不用，责任在你。**
